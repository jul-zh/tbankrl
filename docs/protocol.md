## Данные и временное разбиение

Используется [KION](https://github.com/irsafilo/KION_DATASET/tree/f69775be31fa5779907cf0a92ddedb70037fb5ae),
версия `f69775be31fa5779907cf0a92ddedb70037fb5ae`: прочитано 5 476 251 строка.
Источник, контрольная сумма CSV и описание разбиения сохранены в
[метаданных](../results/metadata/protocol.json).

| Часть | Граница времени, UTC | Назначение |
| --- | --- | --- |
| Обучение | $t<\text{2021-07-21}$ | Параметры моделей, словарь и статистики |
| Проверка | $\text{2021-07-21}\le t<\text{2021-08-06}$ | Настройки и выбор сохраненных состояний |
| Тест | $t\ge\text{2021-08-06}$ | Итоговый расчет с фиксированными весами |

Границы определены по 80% и 90% уникальных дат и закреплены для всех сравнений.
Одна дата не разделяется между частями. События в контексте имеют время
**строго меньше** времени цели. При оценке разрешена реальная более ранняя
история, включая события предыдущих частей; веса при этом не обновляются.

### Что позволяет восстановить KION

`last_watch_dt` - последняя дата просмотра, а не точный журнал всех действий.
Внутри одинаковой пары «пользователь - дата» порядок неизвестен. Такие цели
исключаются; соответствующие позиции истории заменяются на `UNK` - токен
неизвестного объекта. Иначе произвольная сортировка создала бы вымышленные
переходы между фильмами.

Цена этого решения - около 60,6% неизвестных позиций в обучении и 61,4%
на проверке. Это существенная потеря информации, а не полноценное восстановление
сессий. Формально соблюденная хронология не устраняет ограничений агрегированных дат.

## Пользователи, каталог и цели

Пользователи отбираются только по обучающей части: минимум пять строк истории.
Исходная когорта содержит 50 000 пользователей и 215 667 пригодных примеров.
Расширение сохраняет эти примеры, добавляет обучающих пользователей до 150 000
и дает 648 685 примеров; 137 918 пользователей имеют пригодные обучающие цели.

Словарь из **11 229 объектов** фиксируется до расширения. Три специальных
токена обозначают заполнение, начало истории и неизвестный объект. Неизвестные
целевые объекты не входят в оценку; неизвестные позиции истории сохраняются
как `UNK`. Популярность и средние награды рассчитываются только по обучению.

На проверке и тесте - по **5000 пользователей**, по одной первой пригодной
цели на пользователя. Пользователи и цели отобраны воспроизводимо, без
использования величины награды. При расширении обучения отложенные примеры,
каталог и даты не меняются. Поэтому сравнения относятся к знакомым каталогу
объектам и отобранной аудитории, а не к новым объектам или всем пользователям.

## Обучающие примеры и маски

Контекст содержит до 32 токенов, короткие истории заполняются справа.
Маска заполнения исключает эти позиции из внимания, причинная маска
запрещает доступ к будущим токенам. Логиты вычисляются по последней непустой
позиции, а целевая метка - отдельный следующий реальный объект.
Это один сдвинутый ответ на префикс, без попадания цели во вход.

Модель награды получает только историю и ID кандидата. `watched_pct`
преобразуется в цель; `total_dur` - наблюдаемый отклик и не используется
как заранее известная длительность фильма. Сглаженное среднее объекта строится
по обучающим строкам, нейросетевая модель награды - по пригодным примерам
следующего объекта. Их обучающие множества различаются: сравнение не является
чистой проверкой архитектуры при идентичных данных.

## Параметры обучения

| Компонент | Основные параметры |
| --- | --- |
| GPT-2 | AdamW, шаг обучения $3\cdot10^{-4}$, пакет 64; разогрев 0,25 прохода, косинусное снижение шага до 10% исходного |
| Модель награды | Размерность представления 64; AdamW, шаг $10^{-3}$, пакет 256, среднеквадратичная ошибка |
| Основной RL | AdamW, шаг $3\cdot10^{-6}$, пакет 32; β=0,3, α=0,3, горизонт 1 |
| Многошаговый вариант | Горизонт 5, дисконтирование 0,95 |

Для AdamW коэффициент уменьшения весов равен 0,01. У GPT-2 проверка
проводится каждые полпрохода; четыре проверки без улучшения на $10^{-4}$
останавливают обучение. Серии RL используют 2000 или 2500 обновлений;
ранние проверки выполняются после 25/50/100 обновлений, затем с заданным
интервалом. Ограничения времени и полные настройки - в
[инструкции запуска](reproduce.md) и [конфигурациях](../configs/).
Состояние модели награды выбирается по ошибке первых 1000 проверочных
примеров; ее итоговые показатели вычисляются на полных 5000 примерах
каждой отложенной части.

## Метрики

Ранжирование выполняется по всему реальному каталогу, без случайной выборки
отрицательных объектов. Для всех моделей совпадают пользователи, цели,
контексты и кандидаты. Специальные токены не рекомендуются; известные объекты
не удаляются автоматически, поскольку их доля исследуется отдельно.

- **Recall@K:** попала ли единственная правильная цель в первые K рекомендаций.
- **NDCG@K:** $1/\log_2(\mathrm{rank}+1)$ при попадании, иначе ноль.
- **Прогноз награды@10:** среднее предсказание замороженной модели награды
  по десяти рекомендованным объектам и пользователям, без скидки на позицию.
- **Покрытие:** доля каталога, появившаяся в первых десяти рекомендациях.
- **Доля известных объектов:** доля позиций, ID которых уже есть в доступном
  контексте. Объекты за `UNK` по ID не распознаются.
- **Концентрация:** доля 1% самых популярных объектов, коэффициент Джини показов
  и пересечение списков детерминированных соседних пар пользователей.

Списки первых K объектов не содержат дубликатов. Повторы внутри сгенерированной
цепочки - другая величина: на шаге t проверяется, встречался ли текущий ID
среди ранее сгенерированных. Основной K=10, также сохраняются метрики при K=20.

## Выбор состояний и итоговая оценка

Исходная GPT-2 выбирается по NDCG на проверке. В первой серии RL допустима
потеря до 5%; до серии с тремя случайными запусками основной порог ужесточен
до 0%. Для каждого запуска выбирается максимальный прогноз награды
при проверочном NDCG не ниже исходной GPT-2. Исходные веса на шаге 0 допустимы,
но все три основных результата - реально дообученные состояния.

Дополнительные пороги - 1%, 2% и 5% потери NDCG. Отдельно сравниваются
одинаковые последние шаги 2500: выбор удачного шага и равная длина обучения
отвечают на разные вопросы. Переранжирование использует заранее заданные
коэффициенты. Тест не участвует в повторном выборе метода, шага или запуска.
Точные веса и шаги итоговой оценки - в [фиксации](../configs/final_selection.json).

Тестовая часть ранее просматривалась в исходном эксперименте. Итоговый расчет
выполнен без перенастройки по нему, но не является новой независимой проверкой.

## Неопределенность и воспроизводимость

Случайные запуски RL используют ключи 42, 123 и 2026. Они меняют пакеты
и сгенерированные действия; исходные веса GPT-2, модель награды и аудитория общие.
Стандартное отклонение рассчитывается с `ddof=1` и не является доверительным
интервалом. Три запуска не образуют 15 000 независимых пользователей.

Парный бутстрэп пересэмплирует одних и тех же пользователей для сравниваемых
моделей: 1000 повторов, 95%-й интервал по квантилям 2,5% и 97,5%.
Для среднего трех политик сначала усредняются значения внутри пользователя.
Это условные интервалы для фиксированных весов, без повторения обучения.
Проверочные интервалы дополнительно ограничены выбором на той же выборке;
поправки на множество сравнений нет. Отсутствие значимого падения не доказывает
статистическую неухудшаемость.

Обучение ограничено временем и числом обновлений. Состояния содержат веса,
оптимизатор, масштабирование градиентов, генераторы случайных чисел и положение
выборки пакетов. Проверка входных контрольных сумм защищает восстановление
от смешения протоколов. Сначала выполняется небольшой запуск и замер скорости;
указанный лимит времени не считается измеренной длительностью.
