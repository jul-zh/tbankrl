# Соответствие заданию

[Обзор](../README.md) · [Исходная постановка](assignment.md)

| Требование | Что сделано | Где смотреть |
| --- | --- | --- |
| GPT-2 для предсказания следующего объекта | Обучение с нуля на ID, сравнение объема данных и размера модели | [Метод](method.md), раздел 1 [экспериментов](experiments.md) |
| Модель награды с учетом истории | Предсказание доли просмотра; RMSE, корреляция и калибровка на отложенных данных | Раздел 2 [экспериментов](experiments.md) |
| Дообучение с подкреплением | REINFORCE, KL и дополнительное предсказание следующего объекта | [Метод](method.md), разделы 3–4 [экспериментов](experiments.md) |
| Изменение поведения и риск эксплуатации награды | Известные объекты, покрытие, популярность, пересечение выдач; ограничения интерпретации | Раздел 5 [экспериментов](experiments.md) |
| Сохранение релевантности | Recall/NDCG по полному каталогу, три случайных запуска, парные интервалы | Раздел 4 [экспериментов](experiments.md), [протокол](protocol.md) |
| Долгосрочная цель | Метка возврата за семь дней, полное окно наблюдения, граница между историческими данными и онлайн-проверкой | Раздел 7 [экспериментов](experiments.md) |
| Несколько шагов вперед | Пять сгенерированных ID, повторы и сравнение реальной/синтетической истории | Раздел 6 [экспериментов](experiments.md) |
| Компромисс награды и релевантности | Вес KL, штраф известного объекта, вес предсказания, горизонт и переранжирование | Разделы 3–4 [экспериментов](experiments.md) |
| Временное разбиение без утечек | Общие даты, строго предшествующая история, обработка совпадающих дат, статистики только по обучению | [Протокол](protocol.md), `tests/test_data.py` |
| Воспроизводимость | Код в модулях, параметры и метаданные, Colab, ограничения времени и восстановление | [Инструкции](reproduce.md), [проверка чисел](../scripts/verify_results.py) |

Выводы включают отрицательный результат: рост предсказанной награды не дает
подтвержденного улучшения пользовательского опыта и может снижать релевантность.
Улучшение возвратов или удовлетворенности по этим экспериментам не заявляется.
