# Численные результаты

[Обзор](../README.md) · [Эксперименты](../docs/experiments.md)

Здесь хранятся небольшие результаты завершенных расчетов. Датасета и весов нет.

| Папка | Содержимое |
| --- | --- |
| `tables/` | Точные значения без округления: исходные модели, варианты RL, контроль и итоговая оценка |
| `figures/` | Компромисс метрик, калибровка, пятишаговая генерация и сдвиг истории |
| `metrics/` | 34 сжатых обезличенных массива численных метрик |
| `metadata/` | Параметры протокола, окружение, происхождение, контрольные суммы и результаты проверок |

## Формат массивов

Каждый файл `metrics/<часть>/<модель>.npz` содержит по 5000 строк:

- `rank`: позиция правильного объекта среди первых 20; ноль означает отсутствие;
- `recall@10`, `recall@20`, `ndcg@10`, `ndcg@20`;
- `rm_reward@10`: средний прогноз награды первых десяти объектов, если доступен.

Порядок строк сохраняет парность между моделями внутри одной части данных.
Исходные ID пользователей/объектов, истории, реальные целевые отклики и списки
рекомендаций исключены. Публикуются результаты оценки, а не фрагмент датасета.

Ранжирование сначала проверено по исходным рекомендациям. Для публикации
сохранен только ранг ответа, позволяющий повторить расчет метрик. Общая
контрольная сумма исходного порядка строк и суммы исходных/публикуемых файлов
записаны в `metadata/arrays.json`.

## Проверка

```bash
python scripts/verify_results.py
python scripts/build_figures.py
```

Проверка не загружает модели и не обучает их. Для 18 тестовых вариантов
воспроизводятся 84 парных интервала, а также интервалы основного среднего
трех запусков. `metadata/test_audit.json` содержит исходную проверку экспорта,
`metadata/verification.json` — проверку опубликованных обезличенных массивов.

`configs/final_selection.json` перечисляет состояния, допущенные до тестовой
оценки. Контрольные суммы полных файлов весов закреплены по этой предварительной
проверке; основной метод, случайные состояния и шаги по тесту не перевыбирались.
Метаданные происхождения связывают этот список с исходной фиксацией.
